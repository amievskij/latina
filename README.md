# Latīna — личный словарь латыни

Приложение для изучения латыни через немецкий: свой словарь, грамматика по мере изучения,
интервальное повторение. Работает как PWA: ставится на телефон и работает без интернета.
Все данные хранятся только на устройстве (IndexedDB), сервера и регистрации нет.

## Установка на телефон

Откройте адрес приложения (ссылка GitHub Pages) **один раз с интернетом**, затем:

**Android (Chrome)**
1. Откройте ссылку в Chrome.
2. Меню **⋮** → **«Добавить на главный экран»** → **«Установить»**
   (или кнопка «Установить приложение» в разделе «Настройки» внутри приложения).
3. Иконка «Latīna» появится на главном экране. Дальше интернет не нужен.

**iPhone (Safari)**
1. Откройте ссылку именно в **Safari**.
2. Кнопка **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **«Добавить»**.
3. Запускайте приложение с иконки на главном экране.

> На iPhone словарь в Safari и словарь в установленном приложении — это два разных хранилища.
> Добавляйте слова уже после установки, из приложения на главном экране.

## Слова по фото

«Главная» → «Слова по фото»: сфотографируйте печатный список (латынь слева, немецкий справа).
Текст распознаётся прямо на телефоне (Tesseract.js, фото никуда не отправляется), после чего
пары можно поправить и добавить в словарь разом. Модуль распознавания (~15 МБ) скачивается
при первом открытии этого экрана — один раз откройте его с интернетом, дальше он работает офлайн.
Рукописный текст не распознаётся; знаки долготы обычно приходится дописывать вручную.

## Группы и формы глаголов

В словаре переключатель «Список / Группы» раскладывает слова по частям речи (Substantive,
Verben, …), глаголы — по спряжениям, существительные — по склонениям, предлоги — по падежу.
В карточке глагола автоматически строятся формы Indikativ Aktiv в шести временах — из полей
Infinitiv, Perfekt и Konjugation. Отложительные и часть неправильных глаголов не спрягаются.

## Уроки грамматики

Вкладка «Уроки»: путь из 20 уроков в пяти разделах (Präsens, падежи, согласование и предлоги,
прошедшие и будущее времена, неправильные глаголы). Каждый урок — 10 коротких упражнений:
выбор формы, «какая это форма», «кто это делает», ввод формы, сопоставление пар. Ошибки
возвращаются в конце урока. Упражнения строятся из слов вашего словаря (если подходящих мало —
из встроенных примеров). Следующий урок открывается после предыдущего; повторное прохождение
повышает уровень урока до трёх звёзд. Перед каждым уроком есть короткая теория с таблицами.

## Напоминания

«Настройки» → «Напоминания»:
- **Напоминание в календаре** — файл .ics с ежедневным событием; работает на Android и iPhone.
- **Уведомления** (Android, приложение установлено на главный экран) — телефон несколько раз в день
  будит приложение, и после выбранного времени оно напомнит, если сегодня ещё не было повторения.
  Как часто проверять, решает Android. На iPhone такой возможности у приложений без сервера нет.

## Слова из учебника

«Настройки» → «Слова из учебника» → кодовое слово → «Загрузить». Слова хранятся в приложении
в зашифрованном виде (data/lehrbuch.json), поэтому в открытом репозитории их прочитать нельзя.

## Резервные копии

«Настройки» → «Экспорт в JSON» — полная копия со всем прогрессом повторений.
«Экспорт в CSV» — таблица слов для Excel (без прогресса).
«Импорт из файла» принимает оба формата и не создаёт дубликатов:

- то же слово из копии (совпал внутренний id) — берётся более свежая версия;
- совпали латынь и немецкий перевод — в существующую карточку дописываются только пустые поля;
- остальное добавляется как новые слова.

Перенос на другой телефон: экспорт в JSON → передать файл → импорт на новом телефоне.

Словарь стирается, если удалить приложение или очистить данные сайта в браузере, поэтому
делайте копию время от времени.

## Обновление приложения

1. Измените файлы.
2. В `sw.js` увеличьте номер версии: `const CACHE = 'latina-v8'`.
3. Загрузите изменения в репозиторий (`git push`).

Телефон подхватит новую версию при следующем запуске с интернетом. Словарь при этом не
затрагивается: он лежит в IndexedDB, а service worker обновляет только файлы приложения.

## Структура

| Файл | Назначение |
|---|---|
| `index.html`, `css/style.css` | разметка и оформление (светлая и тёмная темы) |
| `js/app.js` | экраны и обработка действий |
| `js/db.js` | хранилище IndexedDB |
| `js/srs.js` | интервальное повторение (вариант SM-2) |
| `js/grammar.js` | части речи и грамматические поля |
| `js/io.js` | экспорт и импорт JSON/CSV |
| `js/util.js` | поиск без диакритики, даты, CSV |
| `js/verbs.js` | автоматическое спряжение глаголов |
| `js/nouns.js` | склонение существительных, формы прилагательных |
| `js/course.js` | уроки грамматики: теория и упражнения |
| `js/basis.js`, `data/lehrbuch.json` | зашифрованные слова из учебника |
| `js/ocr.js`, `vendor/tesseract/` | распознавание слов с фото (Tesseract.js, Apache 2.0) |
| `sw.js`, `manifest.webmanifest`, `icons/` | офлайн-работа и установка |
| `tools/` | локальный сервер, тесты логики, генератор иконок |

Локальный запуск: `node tools/serve.mjs` → http://localhost:8123.
Тесты логики: `node tools/test-logic.mjs`.
